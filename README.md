# Signal K MCP

Native, read-only MCP access to Signal K telemetry and approved plugin capabilities, using existing Signal K identities and permissions.

This repository is being initialized. The implementation will be reviewed through a feature pull request. The local proof of concept has been tested against Signal K 2.33.0; no npm/AppStore release or vessel deployment is claimed.

- [Project brief](BRIEF.md)
- [Repository working instructions](AGENTS.md)

Initial scope: Streamable HTTP, batched telemetry, a compact capability registry, and permission-aware discovery. Sandbox execution and vessel-control operations are outside the current implementation scope.
